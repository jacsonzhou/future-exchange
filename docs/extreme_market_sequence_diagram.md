# 极端行情完整交易链路时序图

> 本文档展示从用户下单到ADL完成的完整交易链路，包含所有核心服务的数据流。

## 服务端口速查

| 服务 | 端口 | 职责 |
|------|------|------|
| API Gateway | 8080 | 统一入口，认证限流 |
| OMS-Core | 8081 | 订单生命周期管理 |
| Hard-Risk-Core | 8082 | 硬风控检查 |
| Match-Engine-Core | 8083 | 撮合引擎 |
| Ledger-Core | 8084 | 双录分录记账 |
| Account-Snapshot-Core | 8085 | 账户快照 |
| Position-Snapshot-Core | 8086 | 持仓快照 |
| Index-Price-Core | 8097 | 指数价格计算 |
| Mark-Price-Core | 8098 | 标记价格计算 |
| Margin-Mode-Core | 8088 | 保证金模式管理 |
| Liquidation-Core | 8089 | 强平服务 |
| ADL-Core | 8090 | 自动减仓 |
| Market-Price-Core | 8095 | 行情生成（计算层）|
| Public-Push-Core | 8096 | 公有推送（WebSocket）|
| Private-Push-Core | 8091 | 私有推送（WebSocket）|
