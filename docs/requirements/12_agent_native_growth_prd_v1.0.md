## 2. 使命与价值主张

### 2.1 使命
`让每个交易员和每个Agent都能被系统化训练，并可证明自己持续变强。`

### 2.2 一句话产品定义
`不是“交易平台 + AI建议”，而是“定义策略 -> 受控执行 -> 自动复盘 -> 能力增量证明”的成长操作系统。`

### 2.3 对用户和AI的共同价值
1. 提供统一能力尺子（Skill Score），避免只看单次盈亏。
2. 提供决策证据链，避免黑箱“拍脑袋下单”。
3. 提供版本迭代机制，支持策略持续优化。
4. 提供低风险训练场景，支持高频试错与复盘。

### 2.4 和交易所/挑战赛的本质区别
1. 交易所解决执行问题，不解决成长证明问题。
2. 挑战赛解决筛选问题，不解决策略迭代问题。
3. 本系统解决“长期可复现地变强”问题。

## 3. 目标用户与核心场景

### 3.1 用户分层
1. 专业交易员（人类）:
   - 目标: 提升纪律与收益质量，减少执行偏差。
2. Agent开发者（Claude Code/Codex/Kimi K2）:
   - 目标: 让Agent策略可测、可控、可复盘、可升级。
3. 半自动交易用户:
   - 目标: 使用AI辅助决策，但保留最终人类确认。

### 3.2 核心场景
1. 场景A: 用户先在模拟盘训练，再迁移到半自动执行。
2. 场景B: Agent输出决策建议，用户审核后一键填单。
3. 场景C: 交易完成后自动进入复盘，生成改进计划。
4. 场景D: 策略版本在竞技场对比，验证是否真的进步。

## 4. 产品原则（必须满足）
1. `安全优先`: Agent不直接持有交易密钥。
2. `证据优先`: 每个结论都需可追溯到订单与决策证据。
3. `同尺评估`: 人和AI使用同一评分规则。
4. `先训练后自动化`: 自动化能力按阶段灰度开放。
5. `可解释`: 决策理由和评分构成必须对用户透明。

## 5. 核心闭环与模块职责

### 5.1 闭环主线
1. 市场/账户上下文输入（ContextPack）。
2. 策略与Agent产出结构化决策（DecisionIntent）。
3. Policy Engine做硬风控校验。
4. 用户执行（模拟盘/半自动）。
5. 系统沉淀证据链（Decision -> Order -> Fill -> Replay）。
6. Skill Score更新与成长建议。

### 5.2 模块目标（已建设页面）

| 模块 | 用户价值 | 成长作用 | 关键动作 |
|---|---|---|---|
| 模拟训练 | 低风险练习 | 建立纪律与执行稳定性 | 任务训练、风险护栏 |
| 策略工坊 | 策略版本化 | 从“感觉”到“可迭代” | 定义Skill、A/B版本 |
| AI决策台 | 结构化建议 | 降低主观噪音 | 预览、校验、采纳填单 |
| 复盘实验室 | 自动归因 | 把亏损转化为改进动作 | 回放、偏差分析、行动项 |
| AI竞技场 | 压力测试 | 验证跨行情稳健性 | 人机同规则对比 |
| Skill榜 | 公平比较 | 提供外部标尺与反馈 | 人机同榜排名 |
| 我的成长 | 长期追踪 | 关注能力增量而非偶然盈利 | 周报、维度提升计划 |

## 6. Skill Score v1.0（评分体系）

### 6.1 总体公式
`Skill Score = 0.30*RAR + 0.20*DDC + 0.15*EXEC + 0.15*CONS + 0.10*RISK + 0.10*REPLAY - PENALTY`

### 6.2 维度定义
1. `RAR`（风险调整收益）:
   - 收益质量，不奖励纯杠杆堆收益。
2. `DDC`（回撤控制）:
   - 控制最大回撤与恢复速度。
3. `EXEC`（执行质量）:
   - 实际执行与计划执行偏差。
4. `CONS`（稳定性）:
   - 跨周期、跨场景表现一致性。
5. `RISK`（风险纪律）:
   - 杠杆、单笔风险、日损控制。
6. `REPLAY`（复盘闭环）:
   - 复盘完成率与改进行动落地率。

### 6.3 违规惩罚 `PENALTY`
1. 越权下单（绕过Policy）: 直接扣 `20~40` 分。
2. 止损缺失或违规取消: 单次扣 `5~15` 分。
3. 高风险连续违例（如连续超杠杆）: 触发冷却，额外扣分。

### 6.4 生效门槛（防刷分）
1. 最小有效样本: `>= 20` 笔交易或 `>= 5` 个有效训练会话。
2. 覆盖场景要求: 至少包含 `趋势/震荡/高波动` 三类中的两类。
3. 样本不足时只展示“临时评分”，不进入公开榜单。

## 7. Claude/Codex 的正确角色（系统约束）

### 7.1 角色边界
1. LLM角色: `决策层`（生成候选决策、解释和复盘建议）。
2. 执行角色: `Execution Service`（由系统执行，受风控约束）。
3. 风控角色: `Policy Engine`（硬阻断，不可被LLM绕过）。

### 7.2 强制规则
1. LLM不持有用户密钥，不直接请求交易所下单。
2. 输出必须为结构化 `DecisionIntent`，禁止自由文本执行。
3. 必须先过 `decision/validate` 才允许进入“采纳并填单”。
4. 所有动作必须记录 `trace_id + decision_id + order_id`。

### 7.3 典型流程
1. Agent读取 `ContextPack`。
2. Agent输出 `DecisionIntent`。
3. Policy Engine校验通过。
4. 用户确认采纳或拒绝。
5. 系统执行并记录全链路证据。

## 8. 成长机制设计（用户与AI都有效）

### 8.1 周训练节奏（建议产品内置）
1. 周一: 设定本周训练目标（如“执行偏差 < 12%”）。
2. 周二至周四: 模拟训练与半自动执行。
3. 周五: 复盘实验室自动生成周报与改进行动。
4. 周末: 策略工坊发布新版本并进行对照实验。

### 8.2 自动成长任务（系统生成）
1. 风控纪律任务: 连续N次交易止损完整率达到阈值。
2. 执行一致性任务: 决策到下单偏差低于阈值。
3. 稳定性任务: 不同波动场景下保持正向评分。
4. 复盘完成任务: 每周至少完成2次有效复盘。

### 8.3 行动闭环（关键）
1. 每次复盘至少输出1条可执行改进动作。
2. 下次策略版本必须绑定上次行动项，形成“改进证据”。
3. 无改进行动的复盘，不计入成长积分。

## 9. 功能需求（v1.0上线范围）

### 9.1 模拟训练
1. 训练模式:
   - 自由模拟
   - 场景训练（趋势/震荡/高波动）
   - 任务训练（目标+约束）
2. 风险护栏:
   - 最大杠杆
   - 单笔风险上限
   - 日内最大亏损
3. 输出:
   - 会话结算
   - 分维度评分
   - 自动复盘入口

### 9.2 策略工坊
1. Skill版本管理（创建、发布、回滚、对照）。
2. 策略输入输出契约检查（Schema校验）。
3. 策略基准测试（同场景多版本对比）。

### 9.3 AI决策台
1. 候选决策列表（置信度、风险暴露、进出场区间）。
2. 规则校验状态（通过/拒绝/需调整）。
3. 一键采纳填单（不自动执行真仓）。
4. 决策理由与证据摘要展示。

### 9.4 复盘实验室
1. 决策-执行-结果时间线回放。
2. 归因拆解:
   - 信号质量
   - 执行偏差
   - 风险纪律
3. 自动生成“下次怎么做”行动卡。

### 9.5 AI竞技场
1. 人类与AI同规则竞技。
2. 固定起始资金、固定风险约束、固定评估窗口。
3. 展示收益曲线、回撤、Skill Score三维排名。

### 9.6 Skill榜
1. 人机同榜同尺，支持维度筛选。
2. 展示最近4周趋势，避免单周运气误导。
3. 展示评分构成，支持申诉入口。

### 9.7 我的成长
1. 能力雷达图与周变化。
2. 成长目标与完成进度。
3. 推荐下一步训练任务。

## 11. 上线指标与验收标准

### 11.1 北极星指标
`连续2周Skill Score提升且有复盘证据的活跃账户数`

### 11.2 核心指标（上线后30天）
1. 周复盘完成率 `>= 55%`。
2. 复盘后策略改版率 `>= 35%`。
3. 训练会话7日留存 `>= 30%`。
4. AI建议采纳后“风险违规下降率” `>= 20%`。
5. Agent开发者周活跃账户数持续周环比增长。

### 11.3 功能验收（Go-Live Gate）
1. 决策校验阻断准确率 `100%`（硬违规不可放行）。
2. 证据链完整率 `>= 99.9%`。
3. Skill Score可回放复算一致率 `100%`。
4. 公开榜单仅包含“有效样本用户”。

## 13. 不该做什么（避免失败方向）
1. 不做“AI直接真仓自动交易”作为首发。
2. 不做只有收益率的榜单。
3. 不做无法追溯证据的“黑箱推荐”。
4. 不做没有风险护栏的高杠杆训练活动。
5. 不做一开始就平台对赌，先完成成长闭环与留存。

## 14. 风险与应对
1. 风险: 用户认为评分不公平。
   - 应对: 公开评分规则、维度分数与证据链下载。
2. 风险: Agent输出不稳定，建议质量波动大。
   - 应对: 强制结构化输出 + 场景基准回放 + 版本门禁。
3. 风险: 用户只追求短期收益，不做复盘。
   - 应对: 把复盘和成长任务绑定权益与榜单曝光。
4. 风险: 高波动期间过度交易。
   - 应对: 风险护栏 + 连亏冷却 + 高频警示。

## 15. 运营与商业化建议（与成长机制绑定）
1. 基础版免费: 模拟训练 + 基础复盘。
2. Pro版订阅:
   - 高级复盘报告
   - 多策略A/B实验
   - Agent API更高额度
3. 成长权益:
   - 达成成长任务可解锁高级功能配额。
   - 竞技场优胜策略可获得展示位与开发者流量。
