## 7. 关键设计原则

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                            合约交易系统核心设计原则                               │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  1. 高性能撮合                                                                   │
│     • Disruptor RingBuffer + 内存 OrderBook                                    │
│     • 单线程撮合（每symbol一线程），避免锁竞争                                    │
│     • 延迟目标: < 1ms                                                          │
│                                                                                 │
│  2. 双录账本 (Ledger)                                                           │
│     • 每笔业务生成两条分录，借贷必平衡                                            │
│     • Ledger 是唯一资金真相源 (Source of Truth)                                  │
│     • 分录不可修改，支持幂等和审计                                               │
│                                                                                 │
│  3. 同步硬风控                                                                   │
│     • 下单前必须完成余额/杠杆/限额检查                                           │
│     • 延迟目标: < 3ms                                                          │
```
